# Demo script (manual — reference with #demo-script when rehearsing)

The one demo path. One clinic, one town, one patient.
**Baystate GI (Springfield) × Holyoke × "Maria"** (synthetic, labelled as such).

1. Map of western MA → click **Holyoke** → pick **Baystate GI**. Week grid fills; morning
   cells turn red. "Red means you can't get there *and* back by bus."
2. Hover a red 8am cell → **day ribbon** shows the bus legs and the gap.
3. **Drag the GI block 8am → 10am** → grid turns green; counter shows +N Holyoke residents.
4. **"Suggest best schedule"** → 3 ranked changes + impact; flash the equity panel.
5. **Rural lens:** Franklin County "no option at all" layer.
6. **Export CHNA report** → PDF opens.
7. **Visit Planner → Maria** (positive FIT, works 7–3, Spanish) → 6-tap barrier check.
8. Banner: **"Needs an escort — transit won't work."** → slot after her shift inside a
   volunteer-driver window + PT-1 pre-filled + Spanish prep sheet.
9. **Phone mock** → day-before itinerary + last bus home + printed QR card.
10. **Kiro IDE:** PBT fails → shrinks to a `24:30:00` after-midnight trip → bugfix spec → green.
11. Back in app: click a number → **"How we know this is right"** drawer.
12. Montage: Web PR → CLI CI gate → Crew Slack alert → published power page.

Every on-screen number is computed from real data. No typed-in numbers.
